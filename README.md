# RS Color Harmonizer

遥感影像多景匀光匀色与镶嵌生产桌面软件。

## 项目目标

面向卫星、无人机和测绘生产场景，提供多景影像的参考色彩匹配、自动匀光匀色、接缝线优化、镶嵌和质量检查能力。首版限定同一传感器、同一区域、相近时间的 GeoTIFF/COG 数据。

## 首版 MVP

- GeoTIFF/COG 导入与元数据识别
- 多景影像浏览、图层管理和透明度控制
- 自动选择参考影像
- 重叠区统计匹配和颜色迁移
- 接缝线生成与羽化
- 前后对比和局部人工修正
- 分块批处理、进度、暂停、取消和日志
- 输出带坐标和元数据的 GeoTIFF/COG

## 技术方向

- 桌面端：Qt 6 + Qt Quick/QML
- 核心：C++20
- 影像：GDAL + OpenCV + Eigen
- 并行：TBB/OpenMP
- 算法验证：Python 独立目录，不进入正式运行时
