# 产品需求说明

## 要解决的问题

遥感生产中，多景影像经常存在亮度、色彩和接缝不一致。人工逐景调整耗时，简单直方图匹配又容易把云、阴影和真实地物变化当成色差。

## 目标用户

- 测绘和遥感生产人员
- 卫星和无人机数据处理团队
- 自然资源、农业、林业、矿山、电力巡检项目团队

## MVP 范围

### 包含

- 同一传感器、同一区域、相近时间的多景 GeoTIFF/COG
- 影像元数据、波段和坐标系检查
- 参考影像选择
- 重叠区统计、颜色迁移、匀光匀色
- 接缝线、羽化和镶嵌输出
- 前后对比和局部人工修正
- 任务队列、取消、日志和结果报告

### 首版不包含

- 跨传感器绝对辐射校正
- 自动消除所有云和阴影
- 跨季节地物变化补偿
- 在线账户、多用户协作和云端计费
- 直接替代行业生产资质或测绘成果审核

## 成功指标

- 处理吞吐量：按平方公里、景数和 GB 统计
- 峰值内存：不同影像尺寸下的稳定性
- 自动处理成功率和人工返工率
- 接缝区域亮度和色差指标
- 输出坐标、NoData、波段和元数据完整性
- 相同输入和参数可重复得到一致结果

## 产品原则

1. 先保证空间和光谱数据正确，再追求视觉效果。
2. 自动结果必须可解释、可回退、可人工修正。
3. 默认保护真实地物变化，不强行把所有区域统一成同一种颜色。
4. 大文件处理不能阻塞界面，所有耗时操作都可取消。
