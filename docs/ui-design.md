# 界面设计

## 工作台布局

参考专业 GIS 工作台的信息架构，但不复制第三方产品的具体视觉资产。

- 顶部：Ribbon，分为项目、影像、匀色、镶嵌、分析、视图和帮助
- 左侧：图层树、文件目录和任务列表
- 中央：地图和影像画布
- 右侧：属性、匀色参数、符号化和处理日志
- 底部：坐标、比例尺、投影、进度和状态

## 主要流程

1. 新建项目，添加影像，检查元数据。
2. 选择参考影像，预览重叠区统计。
3. 调整匀色参数，实时预览，应用到当前景或批次。
4. 生成接缝线，检查异常，输出 GeoTIFF/COG。
5. 查看质量报告，保存工程和处理记录。

## 视觉风格

- 默认浅色主题，灰白背景和蓝色强调色。
- 地图画布优先，工具面板保持克制。
- 重要操作使用图标和文字，次要操作收进菜单。
- 所有参数控件显示单位、范围、默认值和恢复默认操作。
- 处理失败必须给出可执行的错误信息。

## 交互要求

- 支持拖入影像和工程文件。
- 支持单景、多景、滑块和闪烁对比。
- 图层支持显示/隐藏、透明度、顺序和锁定。
- 批处理显示当前景、总进度、剩余时间和取消按钮。
- 工具参数和结果可以保存到工程文件。
